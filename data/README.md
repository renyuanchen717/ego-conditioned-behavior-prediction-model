# Dataset not distributed
The owner explicitly excluded dataset publication. No samples, trajectories, scene caches, or training/validation index are bundled.
Training: 61,975 eligible samples; validation: 7,776, scene-disjoint. Requested training set 62,208 minus 233 irregular-timestamp samples.
1 second history (11 states including t=0), 8 seconds future (80 states), 10 Hz. Non-SDC influencers may be conditioning agents.
WOMD terms require registered recipients for distribution of source data and modifications. Obtain native data from https://waymo.com/open/ and InterHub annotations from https://github.com/zxc-tju/InterHub .
See ../docs/DATA_FORMAT.md for the model cache schema. Checkpoints are provided for inference without retraining.
