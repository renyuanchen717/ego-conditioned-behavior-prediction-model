# Interaction K=12 interface audit

Actual project base: d4f4013ea3c175bfe73db82d9aa9699a335b4bc5. Actual local NDPNet commit: 814544e98171f2bd1e27e63f99aa4ba6794f05ab. No applicable AGENTS.md was found in the inspected project/parent locations. Existing locked artifacts are retained.

The audited `FrozenFeatures` wrapper returns `mu [N,6,80,2]`, `log_w [N,6]`, `Ea [A,128]`, `Em [M,128]`, target indices, context IDs, target IDs, ego identity, target origins and yaws. `Ea` and `Em` are actual frozen encoder outputs (`x_a[:,-1]`, `x_pl[:,-1]`). Example audited scene: 19 context agents including ego, 18 targets, 225 map tokens. These are not invented embedding interfaces.

Existing context.pt contains agent positions/velocity/heading, current-observation masks, history validity, ordered IDs, map polygon position/orientation, and the original graph. Future agent states and future graph validity are zeroed before backbone inference. FrozenBackbone overrides train() to remain eval and disables gradients; the new online guard enforces the same invariant.

Existing native TFRecord and targets.npz provide exact timestamps, the conditioning SDC identity, an 80-step recorded ego plan, target futures and validity. Scene manifest has original scene IDs and overlap-cluster group IDs. Audited split: 11,136 InterHub training scenes and 2,000 external validation / 2,000 external test scenes. Exact scene and overlap-cluster IDs are disjoint. Original driving-session IDs are unavailable; no full session-disjoint claim is made.

The new extractor uses a single existing full scene graph and native scenario per group, never stitches target rows based on sid. It adds a compound scene/timestamp/ego group ID, all current context IDs, ego role, native availability, separate masks, current poses/velocity, 11-frame histories and true historical masks, map geometry, and common-frame metadata. Target-local native/GT and scene-frame geometry are explicitly separated. Ego native futures are not used; ego receives the supplied plan representation. Unknown object types can remain context, while the original valid vehicle/pedestrian/cyclist targets are preserved.

Default context cap is disabled to preserve targets. If explicitly enabled, truncation is based on current distance and stable ID order and is rejected if it would drop original prediction targets. Map tokens are capped at 256 nearest current ego position (history-only resource cap); full frozen agent features already encode the original map. No future target validity selects context. Full ego future validity is checked from native records.

Additional dependency for extraction: torch-geometric to deserialize trusted graph caches and the official WOMD Scenario protobuf package. Training consumes compact plain-tensor caches and does not load raw graphs or backbone weights. The model receives only an inference whitelist; GT/future_valid are separate loss arguments. No cache or raw dataset is added to the public repository.
